# Omarchy YubiKey 0.2.1

Updates the optional GNOME Keyring helper with consistent English text and
refreshes the project documentation.

- Translate CLI help, password/PIN prompts, notifications, status output and
  error messages into English.
- Translate and clarify source comments, including PIN requirements, key-touch
  cancellation and keyring merge verification.
- Correct the `check` message to describe password length in bytes.
- Refresh the README and Keyring guide, and document writing conventions for
  future contributions.

## Upgrade and component versions

The suite is **0.2.1** and the optional Rust Keyring helper is **0.1.1**.
Standalone lock and Polkit plugins remain at **0.2.0**; their only source changes
in this release are comments, so they do not need a separate update.

To update the helper, build and install it from this release using the
[Keyring guide](../keyring.md#build-and-install). Existing enrolled credentials
and encrypted stores remain compatible; rebuilding and replacing the helper
does not require re-enrollment. The helper still requests touch only during
unlock.

Authentication policy, relying-party IDs, encryption and storage formats are
unchanged. This release does not require PAM or boot-configuration changes.

## Downloads

`omarchy-yubikey-0.2.1-source.tar.gz` contains the complete source suite, including
the updated Keyring helper. `SHA256SUMS` records its SHA-256 checksum. As with
previous releases, no prebuilt executables or release signatures are supplied.

## Validation and limits

Local software validation passed 5 Rust tests, 9 Node tests and 49 Python tests,
including isolated native PAM integration tests. Rust formatting, shell syntax,
plugin validation, publication checks and secret scans also passed. The helper
was built in release mode, and its version and English command help were checked.

These checks do not establish new hardware or session-recovery qualification.
See the [security model](../security-model.md) for the existing limitations.
