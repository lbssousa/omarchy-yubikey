# Omarchy YubiKey 0.5.2

This maintenance release integrates the reviewed Dependabot batch in
[PRs #5–#15](https://github.com/marselnenaj/omarchy-yubikey/pulls?q=is%3Apr+author%3Aapp%2Fdependabot).
It includes all fixes and dependency monitoring from [0.5.1](0.5.1.md).

## Reviewed updates

- Update both workflows to the immutable `actions/checkout` 7.0.1 commit, keeping
  read-only token permissions and credential persistence disabled. These workflows
  use push/pull_request events, not privileged pull_request_target checkouts.
- Update Rust native-build, FFI, procedural-macro and asynchronous dependencies.
  The combined lockfile retains patched libz-sys 1.1.31 and async-executor 1.14.1.
- Update chacha20poly1305 to 0.11 with its `zeroize` feature explicitly enabled.
  The dependency moved key erasure behind an opt-in feature; the original bot
  patch needed this correction before merging. A compile-time test prevents
  silently disabling the cipher's ZeroizeOnDrop contract in future updates.

## Existing encrypted stores

The store remains version 1, with the same HKDF information, ChaCha20-Poly1305
parameters and credential-ID associated data. An isolated legacy 0.10.1 build
generated a synthetic encrypted fixture. The new implementation decrypts it and
rejects a wrong hmac-secret, changed credential ID and modified ciphertext.
No actual enrollment or password store was used in testing. Updating does not
re-enroll credentials, require a format migration or rewrite the store.

The suite/setup plugin is **0.5.2**. Standalone lock/Polkit plugins remain **0.3.0**
and the Rust helper's application version remains **0.2.0**. Updating source alone
does not rebuild a previously installed helper; rebuild with `cargo build --release
--locked` when deploying the new dependency set.

## Maintenance policy

Dependabot groups routine minor/patch version updates, while crypto/hardware-auth
dependencies and major updates remain separate for review. Security updates are
outside these routine version groups. Updates are not auto-merged; the daily
RustSec audit, build-output regression check and existing suites remain enabled.
The documented zbus maintenance notices still require a separate API migration.

## Install and downloads

```sh
omarchy plugin update yubikey.setup
```

Downloads contain the exact tagged source and SHA256SUMS, without prebuilt
executables. Existing [0.5.0 feature limits](0.5.0.md) and the
[0.5.1 build-output guidance](0.5.1.md#build-output-disclosure) still apply.

This release does not claim fresh hardware authentication, PAM recovery,
keyring-session or boot qualification. Compatibility tests use synthetic data.

## Verification

The combined dependency set passed a release build, 120 Python tests, 17
JavaScript tests and 9 Rust tests, formatting, translation consistency, shell/YAML
syntax and the real dynamic-zlib build-output regression check. A negative
compile check confirms that removing the zeroize feature breaks the new guard.
The current RustSec database reports no known vulnerabilities in this lockfile;
the three documented maintenance notices remain visible.
