# Omarchy YubiKey 0.3.0

Adds all 50 Omarchy languages and explicit safeguards for multiple local accounts.

- Localize Keyring help, prompts, notifications, status and errors; guided setup;
  enrollment tools; the PAM fallback prompt; lock and Polkit views.
- Follow the account's Omarchy language choice. Shell labels update live, with
  right-to-left layouts for Arabic, Hebrew, Persian and Urdu. The helper accepts
  `--language CODE`; setup passes its resolved language through sudo explicitly.
- Bundle complete catalogs locally. Missing entries fall back to the base
  language and then English; no translation service is used at runtime.
- Preserve commands, credential data and confirmation literals. The PAM gate
  still requires the literal word `password`, and plugins recognize both legacy
  English and all translated gate prompts. Unknown backend prompts stay intact.
- Wrap long lock-screen labels and size the Polkit key view for translated text.
- Preserve other accounts' enrollments. Changing shared PAM policy while other
  accounts have keys now requires an explicit administrator choice.
- Check transaction contents and permissions before manual rollback, stopping
  before writing if a later account enrollment or configuration change conflicts.
  Legacy backups without conflict checks require manual review and restoration.

## Upgrade and component versions

Suite and standalone shell plugins are **0.3.0**. The optional Rust Keyring helper
is **0.2.0**. Existing credentials and encrypted stores remain compatible;
re-enrollment is not required just to update the software.

Build and replace the helper using the [Keyring guide](../keyring.md#build-and-install).
Update standalone plugins with their usual Omarchy update command. Existing PAM
installations keep working with the new plugins; rebuild/install the fallback
module through reviewed setup to translate its terminal prompt too. Updating
source alone does not change installed system PAM or replace a running helper.
The helper's normal unlock remains touch-only.

Run desktop setup separately as each Linux user. PAM policy is shared; stores,
plugins, backups and language choices are per account. Read the
[multiple-account guide](../multi-user.md) before changing shared policy or
restoring a backup. LUKS enrollment remains volume-scoped and separate.

## Downloads

The suite source archive includes helper 0.2.0 and both plugins. Separate lock
and Polkit source archives include their loaders, all 50 catalogs and provenance
hashes. `SHA256SUMS` covers the three archives. No prebuilt executables or release
signatures are supplied.

## Validation and limits

Local validation passed 7 Rust tests, 12 Node tests and 62 Python tests. Coverage
includes actual isolated Linux-PAM conversations in all 50 languages, stable
confirmation behavior, catalog key/placeholder/literal parity, standalone-export
provenance, language isolation between synthetic accounts, preservation of other
users' mappings, shared-policy confirmation and conflicting/legacy rollback.

The release helper was built and its command/enrollment help exercised in all
50 languages. Formatting, shell syntax, QML lint, plugin validation, publication
checks and secret scans passed. Lock views switched live between German,
Arabic, Japanese and English using both the compatibility loader and the native
Omarchy translation API. Polkit views rendered with a synthetic backend. These
were offscreen UI checks, not real authentication or session-lock qualification.

The locale roster matches Omarchy's upstream registry at commit
`5f2fb785562b2b6cd9a58787a3bfd673568fe9dd`. Initial translations reuse matching
Omarchy text and machine-assisted project messages; not every language has had
native-speaker review. See [Languages](../languages.md) for maintenance and
[Security model](../security-model.md) for the existing limitations.
