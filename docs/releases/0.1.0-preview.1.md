# Omarchy YubiKey 0.1.0-preview.1

First public source preview: touch-to-authenticate sudo, a theme-aware Polkit
dialog, a parallel-flow lock screen and an optional GNOME Keyring helper for
compatible Omarchy 4 systems.

- Guided installation with feature selection, key enrollment, PAM preflight,
  backups, password/key checks and rollback.
- Separate standalone plugin repositories for standard Omarchy plugin installs.
- Password fallback remains available. The provided touch-only PAM route does
  not require a FIDO2 PIN and is not mandatory two-factor authentication.
- MIT-licensed source, setup/removal documentation and automated software checks.

## Downloads

`omarchy-yubikey-0.1.0-preview.1-source.tar.gz` contains the complete source suite.
The two `omarchy-yubikey-lock` and `omarchy-yubikey-polkit` archives contain one
plugin each, with their manifest at the archive's top-level project directory.
`SHA256SUMS` records the checksum of each archive. These are source downloads;
there are no prebuilt helper executables or signatures in this preview.

## Validation and limits

Rust, JavaScript and Python software tests pass, including isolated tests for
PAM preservation, mapping merges, file permissions, rollback and interrupted
writes. Plugin manifests and QML syntax were checked on the source environment.
No fresh end-to-end hardware enrollment, real session-lock recovery test or
multi-device compatibility matrix has been completed for this extracted release.
The optional Keyring helper uses a GNOME internal D-Bus method and needs a FIDO2
key with `hmac-secret` support. Keep a recovery root shell open during setup.

Use the installation and security-model documentation before enabling the
plugins. This release is a preview, not a security audit or marketplace approval.
